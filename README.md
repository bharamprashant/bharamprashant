## How I work

- **Measure before claiming:** dev/test splits, held-out evaluation, the weakest metric shown, not hidden.
- **Controls in code, not in prompts:** redaction, citation checks and approval gates that hold even when the model gets it wrong.
- **Run AI like a regulated program:** DPIA, DORA vendor assessment, go/no-go gates and an audit trail.
